STM32 Based 1970's Keyboard to USB HID Adapter

This was my first PCB I designed. Based around an STM32, this was designed to be a keyboard HID controller for a terminal keyboard from 1978 I had bought on eBay. I designed both the schematic and board layout, and I hand soldered the PCB, wrote the firmware, and validated this project.

I might revist this project again in the future and make the physical board layout smaller. It was not very well designed as in everything is a little spaced out too much for my liking upon revisiting, but for a first PCB and STM32-based board, I think it came out pretty good (also that black PCB looks awesome!). The firmware is finished, and the keyboard works as expected albeit a bit stiff given it uses keytronic foam and foil "switches".
